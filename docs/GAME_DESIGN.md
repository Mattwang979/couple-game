# 《釣到你了！》玩法企劃

> 情侶吃飯、排隊、無聊時，兩支手機打開網頁就能連線對戰的釣魚遊戲。
> 不用登入、不用下載，兩人輪流當「魚」和「漁夫」。

---

## 1. 一句話概念

「你釣我、我躲你」的**非對稱 1v1 手機對戰**。

- 一局約 1～2 分鐘
- 一場 6 局：每人當 3 次魚、3 次漁夫
- 一頓飯剛好玩完一場，輸的人轉懲罰輪盤

---

## 2. 開局流程

1. A 打開網頁 → 按「開房間」→ 畫面顯示 **4 位數房號 + QR code**
2. B 輸入房號或掃 QR code 加入（不用註冊、不用登入）
3. （可選）設定本場賭注：從懲罰清單勾選或自己輸入
4. 猜拳決定誰先當漁夫
5. 雙方**同時秘密選角**：選完才一起揭曉 → 互相克制，有猜心理戰

---

## 3. 每局三階段

### 階段一：暗流試探（心理戰，最多 75 秒）

畫面是**側面剖面圖**：上面是天空和碼頭上的漁夫，中間是水面和浮標，下面是水底（水草、珊瑚、光束、氣泡、路過的小魚）。

兩人看到的畫面**不一樣**：

| | 魚的畫面 | 漁夫的畫面 |
|---|---|---|
| 看得到 | 清澈的水下世界、魚鉤和蚯蚓的位置、咬餌範圍 | 水下很混濁，只看得到淡淡的魚影、魚游動冒的氣泡、魚靠近水面時的漣漪 |
| 操作 | 虛擬搖桿游動（左右 + 上下深淺） | 點水裡拋竿（點哪裡浮標落哪、點多深鉤子沉多深）、按「提竿！」 |

**魚的目標：吃掉 3 個餌就贏這局。**

- **按住「假咬」**：浮標往下沉，但不會吃到餌（騙漁夫提竿）
- **按住「真咬」**：浮標一樣往下沉，吃餌進度上升（累積 1.4 秒吃掉一個餌）
- 兩種在漁夫眼中幾乎一樣，唯一的破綻是：真咬咬久了浮標會越沉越深（河豚連這個破綻都沒有）

**漁夫的目標：在魚「真咬」的那一瞬間提竿 → 中魚，進入階段二。**

- 魚在假咬（或根本沒咬）時就提竿 → 落空，漁夫損失一個餌
- 魚剛放開真咬的 0.2 秒內提竿也算中（抵銷網路延遲）
- 漁夫總共 5 個餌，用完直接輸掉這局

**攻防道具**

- **📡 聲納（漁夫）**：冷卻 6 秒（科學家 3.5 秒），掃描時魚的位置亮 0.9 秒，魚的畫面會提示「被掃到了」
- **🌿 海草叢（魚）**：水底有兩片茂密海草，魚躲進去漁夫看不到魚影、聲納也掃不到；但海草離餌遠，魚還是得出來覓食
- **🦐 小蝦點心**：每 8～12 秒隨機出現一隻（存在 7 秒），魚吃到大招 +40 氣、吃餌進度 +25%。漁夫也看得到（比較淡），可以預判魚會往哪游

**刺激點**

- 浮標動畫 + 手機震動 + 心跳音效，魚吃得越多，心跳越快
- 最後 10 秒心跳越來越快、計時器變紅跳動
- 魚：要真咬才有進度，但真咬就有被釣的風險
- 漁夫：太急會被假動作騙，太慢魚就把餌吃光
- 規則很簡單，兩邊一直在互猜對方會不會出手

### 階段二：熱血拔河（最多 60 秒）

中魚後切換成全螢幕拔河畫面：

中魚瞬間會有**慢動作特寫**：鏡頭拉近魚鉤、白光一閃、速度線。拔河時魚線繃直、**釣竿跟著張力彎曲**，張力越高畫面越晃，快斷線時四周閃紅框。

```
距離 [■■■■■■□□□□] 32m 起跳，拉到 0 ＝ 釣起來，被拖到 65m ＝ 逃走
張力 [■■■■■■■□□□]  ← 太滿會斷線、太空會脫鉤
對決 [🎣■■■■⚡□□□🐟] ← 誰最近點得快就往誰那邊推
```

**雙方比手速**：漁夫狂點「收線」、魚狂點「掙扎」。兩邊都每秒點 8 下時漁夫大約六成能拉上來，點得比較快的一方明顯佔優勢。

**漁夫**

- 狂點 / 畫圈收線 → 拉近距離（距離到 0 ＝ 釣起來）
- 要控制張力：太高斷線、太低脫鉤，兩種都是魚贏
- 魚掙扎也會把張力往上推，所以要邊點邊看張力條。張力進入紅區時手機會一直震、張力條閃紅
- 張力超過上限要**撐 0.35 秒**才會真的斷，看到「快斷了！」馬上停手還救得回來

**魚**

- **狂點「掙扎」**：每點一下往外拉、拉緊線、集衝刺氣（體力會慢慢掉，點太快會累）
- **衝刺必殺**：衝刺氣集滿後滑動畫面衝刺——**往右 = 往外衝**（拉遠又拉緊）、**往左 = 衝向漁夫**（線突然變鬆，不趕快收線就脫鉤）、**上 / 下 = 竄游、下潛**。沒集滿時滑動會提示「還沒集滿」
- 魚衝刺時，漁夫的收線鈕上方會跳出**大紅色反制按鈕**（畫面那一側也會閃紅、手機震動），**1 秒內按下去**（或往反方向滑）就能擋下，慢了就被拉遠、張力暴增

**「躍出水面」QTE**

- 魚可以消耗體力跳出水面
- 魚跳起來的時候，漁夫要**放手不收線**，這時還在收線就會斷線（真實釣魚也是這樣）

**體力系統**

- 雙方都有體力條，越累動作越慢
- 最後幾秒常常翻盤

### 階段三：結算

- **釣到** → 漁夫得分 ＝ 魚的重量分 + 連擊獎勵
- **魚逃掉 / 吃光餌 / 漁夫沒餌** → 魚得分
- **對方視角重播 3 秒**：例如「原來你剛剛一直在假咬！」，讓兩個人邊看邊笑

## 4. 角色

每個角色都有：**被動能力** + **一次性大招**（大招靠集氣，在階段一或二釋放）。

### 魚種

| 魚 | 定位 | 重量分 | 被動 | 大招 |
|---|---|---|---|---|
| 🐟 鯉魚 | 平衡新手 | 中 | 數值平均，沒有明顯弱點 | **鯉躍龍門**：連續跳出水面 3 次，漁夫要連過 3 次 QTE |
| 🦈 鯊魚 | 力量型 | 高 | 拔河力量 +30%，但魚影超大、很好找 | **咬斷**：張力瞬間 +55，漁夫正在狂點又不停手就會斷 |
| 🐡 河豚 | 心機型 | 中 | 真咬和假咬的浮標一模一樣，完全看不穿 | **膨脹**：3 秒內漁夫收線無效 |
| 🐙 章魚 | 搗蛋型 | 中 | 觸手長，離餌遠一點也咬得到 | **噴墨**：漁夫畫面被墨汁遮住 3 秒，要用手指擦掉 |
| ⚡ 電鰻 | 控制型 | 中 | 游速最快 | **放電**：漁夫左右操作反轉 3 秒 |
| 🐠 小丑魚 | 撒嬌型 | 低 | 體型小、分數低，但最難抓 | **裝可憐**：漁夫畫面跳出「放我走好不好🥺」，連點 10 下才能關 |

### 漁夫

| 漁夫 | 定位 | 被動 | 大招 |
|---|---|---|---|
| 👴 老漁夫 | 穩健型 | 線比較耐拉（張力 115 才斷） | **穩如泰山**：3 秒內張力不會變 |
| 🏴‍☠️ 海盜船長 | 爆發型 | 收線力量 +30% | **魚叉**：直接拉近 12 公尺 |
| 🧑‍🔬 科學家 | 偵查型 | 魚影比較清楚、聲納冷卻只要 3.5 秒 | **超級聲納**：魚的位置亮 3 秒（躲海草叢也沒用）；拔河時反應時間加倍 |
| 📱 釣魚網紅 | 節奏型 | 連擊加分 | **開直播**：觀眾瘋狂打賞，收線速度 ×2 持續 3 秒 |
| 👵 阿嬤 | 心理戰型 | 多 1 個餌 | **回家吃飯了！**：魚 2 秒不能動 |
| 🧒 小屁孩 | 亂來型 | 拋竿超快 | **大哭**：魚的畫面劇烈晃動、操作延遲 |

### 角色相剋（秘密選角的樂趣）

| 這招 | 被這個剋 | 原因 |
|---|---|---|
| 🐡 河豚「膨脹」 | 👴 老漁夫「穩如泰山」 | 張力不變，等膨脹結束再收 |
| 🦈 鯊魚「咬斷」 | 👴 老漁夫 | 安全區寬，比較不會斷 |
| 🐙 章魚「噴墨」 | 🧑‍🔬 科學家「超級聲納」 | 看不到畫面，但知道魚在哪 |
| 🏴‍☠️ 海盜「魚叉」 | ⚡ 電鰻「放電」 | 操作反轉，魚叉射歪 |
| 📱 網紅「開直播」 | 🐡 河豚「膨脹」 | 收線無效，速度 ×2 也沒用 |
| 👵 阿嬤「回家吃飯」 | 🐠 小丑魚 | 本來就小、不動也很難找 |

## 5. 增加刺激感的機制

### 隨機事件（每局 30% 機率出現一個）

- 🌟 **黃金魚時刻**：這局分數 ×3
- ⛈️ **暴風雨**：漁夫視野變差、浮標亂晃
- 🦀 **螃蟹偷餌**：隨機偷走一個餌（魚和漁夫都會被影響）
- 🌙 **夜釣**：畫面變暗，只有浮標會發光

### 翻盤機制

- **最後一局分數 ×2**，落後的人還有機會贏
- 落後太多的一方大招集氣比較快

### 角色演出

- 漁夫是「手繪身體 + emoji 頭」，每位有自己的服裝帽子（老漁夫草帽、海盜三角帽眼罩、科學家白袍、阿嬤頭巾）
- 姿勢會跟著狀態變：等待時呼吸、拋竿甩竿、提竿後拉；拔河時蹲馬步、張力越高越往後仰、轉捲線器、冒汗；勝利舉竿跳、失敗跌坐
- 魚會擺尾、咬餌時一張一合，衝刺時拉長加殘影和速度線
- **收線連擊**：連續收線會累積「連擊 ×N」，10 下起火、30 下畫面兩側出現速度線，對方也看得到
- **角色喊話**：中魚、連擊、危險、擋下、被拖走、大招、勝負時角色會喊台詞（每個角色有專屬台詞）
- **打擊感**：擋下 / 被拖走 / 中魚時畫面停格一下、閃白光、跳出「BLOCK!」「+7m!」大字
- **氣勢光環**：拔河時漁夫有藍色火焰（連擊越高越旺）、魚有紅橘火焰；大招集滿時角色外圈發光

### 感官回饋

- 手機震動：魚咬餌、張力過高、斷線
- 畫面震動 + 音效 + 背景心跳聲
- 提竿瞬間用慢動作特寫，釣起來時魚會在空中轉一圈

### 快速嗆聲（一鍵送出，對方畫面會跳出來）

- 😏「就這樣？」
- 😭「求放過」
- ❤️「愛你所以不放」
- 🤡「被騙了吧」

## 6. 情侶專屬設計

### 賭注輪盤

開局前設定，結束時輸家轉輪盤。預設選項：

- 餵對方吃一口
- 幫對方買飲料
- 按摩 5 分鐘
- 幫對方拍 10 張美照
- 今天洗碗
- 說三個對方的優點
- ✏️ 自訂

### 戰績紀錄（存在手機本機，不用帳號）

- 歷史勝負場數
- 最常用的魚 / 漁夫
- 稱號：「最會假咬的人」、「提竿之神」、「斷線王」、「餌料殺手」

### 吃飯友善

- 一隻手就能玩
- 一局很短，可以隨時暫停（上菜了！）
- 不用聲音也能玩，靠震動和畫面提示

## 7. 技術方向（之後開發參考）

| 項目 | 方案 |
|---|---|
| 前端 | 純網頁：HTML + Canvas + JavaScript，可愛卡通 + Emoji 畫風 |
| 連線 | PeerJS（WebRTC P2P），用 4 位數房號 / QR code 配對 |
| 部署 | GitHub Pages（免費、不用伺服器） |
| 判定 | 開房間的手機當「主機」，負責所有判定，另一支只送操作 → 兩邊結果一定一致 |
| 存檔 | localStorage（戰績、自訂懲罰） |

**已知風險**

- 部分行動網路的 NAT 可能讓 P2P 連不上 → 提示「兩人連同一個 Wi-Fi」，之後可加 TURN 伺服器
- iOS Safari 不支援網頁震動 → iPhone 改用畫面閃爍 + 音效

### 開發進度

**第一版（已完成）**

- 4 魚（鯉魚、鯊魚、河豚、章魚）+ 4 漁夫（老漁夫、海盜、科學家、阿嬤）
- 階段一 + 階段二 + 結算，最後一局 ×2
- 房號 / QR code 連線、賭注輪盤、暫停（切出 App 自動暫停）
- 所有數值集中在 `js/data.js`，方便之後調平衡

**第二版**

- 其餘角色（電鰻、小丑魚、網紅、小屁孩）
- 隨機事件、對方視角重播、快速嗆聲
- 戰績與稱號
