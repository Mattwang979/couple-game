# 《釣到你了！》玩法企劃

> 情侶吃飯、排隊、無聊時，兩支手機打開網頁就能連線對戰的釣魚遊戲。
> 不用登入、不用下載，兩人輪流當「魚」和「漁夫」。

---

## 1. 一句話概念

「你釣我、我躲你」的**非對稱 1v1 手機對戰**。

- 一局約 60–90 秒
- 一場 6 局：每人當 3 次魚、3 次漁夫
- 一頓飯剛好玩完一場，輸的人轉懲罰輪盤

---

## 2. 開局流程

1. A 打開網頁 → 按「開房間」→ 畫面顯示 **4 位數房號 + QR code**
2. B 輸入房號或掃 QR code 加入（不用註冊、不用登入）
3. （可選）設定本場賭注：從懲罰清單勾選或自己輸入
4. 猜拳決定誰先當漁夫
5. 雙方**同時秘密選角**：選完才一起揭曉 → 互相克制，有猜心理戰

---

## 3. 每局三階段

### 階段一：暗流試探（心理戰，約 30 秒）

兩人看到的畫面**不一樣**：

| | 魚的畫面 | 漁夫的畫面 |
|---|---|---|
| 看得到 | 整個水下世界、所有餌的位置 | 只有水面、浮標、偶爾閃過的魚影和漣漪 |
| 操作 | 虛擬搖桿游動 | 點水面拋竿（點哪拋哪）、按「提竿！」 |

**魚的目標：吃掉 3 個餌就贏這局。**

- **點一下** ＝ 輕啄（假動作）：浮標輕晃，但不加進度
- **長按** ＝ 真咬：吃餌進度條上升，浮標往下沉

**漁夫的目標：在魚「真咬」的那一瞬間提竿 → 中魚，進入階段二。**

- 魚在假咬時就提竿 → 魚被嚇跑、漁夫損失一個餌
- 漁夫總共 5 個餌，用完直接輸掉這局

**刺激點**

- 浮標動畫 + 手機震動 + 心跳音效，魚吃得越多，心跳越快
- 魚：要真咬才有進度，但真咬就有被釣的風險
- 漁夫：太急會被假動作騙，太慢魚就把餌吃光
- 規則很簡單，兩邊一直在互猜對方會不會出手

### 階段二：熱血拔河（約 20–40 秒）

中魚後切換成全螢幕拔河畫面：

```
魚 ◀━━━━━━━━━━●━━━━━━━━━━━━▶ 岸邊
         距離：32m

張力 [■■■■■■■□□□]  ← 太滿會斷線、太空會脫鉤
```

**漁夫**

- 狂點 / 畫圈收線 → 拉近距離（距離到 0 ＝ 釣起來）
- 要控制張力：太高斷線、太低脫鉤，兩種都是魚贏

**魚**

- 往左 / 右 / 下滑動掙扎
- 漁夫要在 **0.8 秒內往反方向滑**才能抵銷，慢了就被拉遠、張力暴增

**「躍出水面」QTE**

- 魚可以消耗體力跳出水面
- 魚跳起來的時候，漁夫要**放手不收線**，這時還在收線就會斷線（真實釣魚也是這樣）

**體力系統**

- 雙方都有體力條，越累動作越慢
- 最後幾秒常常翻盤

### 階段三：結算

- **釣到** → 漁夫得分 ＝ 魚的重量分 + 連擊獎勵
- **魚逃掉 / 吃光餌 / 漁夫沒餌** → 魚得分
- **對方視角重播 3 秒**：例如「原來你剛剛一直在假咬！」，讓兩個人邊看邊笑

## 4. 角色

每個角色都有：**被動能力** + **一次性大招**（大招靠集氣，在階段一或二釋放）。

### 魚種

| 魚 | 定位 | 重量分 | 被動 | 大招 |
|---|---|---|---|---|
| 🐟 鯉魚 | 平衡新手 | 中 | 數值平均，沒有明顯弱點 | **鯉躍龍門**：連續跳出水面 3 次，漁夫要連過 3 次 QTE |
| 🦈 鯊魚 | 力量型 | 高 | 拔河力量 +30%，但魚影超大、很好找 | **咬斷**：張力瞬間暴增，漁夫不立刻放線就斷 |
| 🐡 河豚 | 坦克型 | 中 | 假咬時浮標幾乎不晃，很難看穿 | **膨脹**：3 秒內漁夫收線無效 |
| 🐙 章魚 | 搗蛋型 | 中 | 可以同時碰兩個餌 | **噴墨**：漁夫畫面被墨汁遮住 3 秒，要用手指擦掉 |
| ⚡ 電鰻 | 控制型 | 中 | 游速最快 | **放電**：漁夫左右操作反轉 3 秒 |
| 🐠 小丑魚 | 撒嬌型 | 低 | 體型小、分數低，但最難抓 | **裝可憐**：漁夫畫面跳出「放我走好不好🥺」，連點 10 下才能關 |

### 漁夫

| 漁夫 | 定位 | 被動 | 大招 |
|---|---|---|---|
| 👴 老漁夫 | 穩健型 | 張力安全區比較寬 | **穩如泰山**：3 秒內張力不會變 |
| 🏴‍☠️ 海盜船長 | 爆發型 | 收線力量強 | **魚叉**：直接拉近 15 公尺 |
| 🔬 科學家 | 偵查型 | 魚影比較清楚 | **聲納**：顯示魚的確切位置 3 秒 |
| 📱 釣魚網紅 | 節奏型 | 連擊加分 | **開直播**：觀眾瘋狂打賞，收線速度 ×2 持續 3 秒 |
| 👵 阿嬤 | 心理戰型 | 多 1 個餌 | **回家吃飯了！**：魚 2 秒不能動 |
| 🧒 小屁孩 | 亂來型 | 拋竿超快 | **大哭**：魚的畫面劇烈晃動、操作延遲 |

### 角色相剋（秘密選角的樂趣）

| 這招 | 被這個剋 | 原因 |
|---|---|---|
| 🐡 河豚「膨脹」 | 👴 老漁夫「穩如泰山」 | 張力不變，等膨脹結束再收 |
| 🦈 鯊魚「咬斷」 | 👴 老漁夫 | 安全區寬，比較不會斷 |
| 🐙 章魚「噴墨」 | 🔬 科學家「聲納」 | 看不到畫面，但知道魚在哪 |
| 🏴‍☠️ 海盜「魚叉」 | ⚡ 電鰻「放電」 | 操作反轉，魚叉射歪 |
| 📱 網紅「開直播」 | 🐡 河豚「膨脹」 | 收線無效，速度 ×2 也沒用 |
| 👵 阿嬤「回家吃飯」 | 🐠 小丑魚 | 本來就小、不動也很難找 |

## 5. 增加刺激感的機制

### 隨機事件（每局 30% 機率出現一個）

- 🌟 **黃金魚時刻**：這局分數 ×3
- ⛈️ **暴風雨**：漁夫視野變差、浮標亂晃
- 🦀 **螃蟹偷餌**：隨機偷走一個餌（魚和漁夫都會被影響）
- 🌙 **夜釣**：畫面變暗，只有浮標會發光

### 翻盤機制

- **最後一局分數 ×2**，落後的人還有機會贏
- 落後太多的一方大招集氣比較快

### 感官回饋

- 手機震動：魚咬餌、張力過高、斷線
- 畫面震動 + 音效 + 背景心跳聲
- 提竿瞬間用慢動作特寫，釣起來時魚會在空中轉一圈

### 快速嗆聲（一鍵送出，對方畫面會跳出來）

- 😏「就這樣？」
- 😭「求放過」
- ❤️「愛你所以不放」
- 🤡「被騙了吧」

## 6. 情侶專屬設計

### 賭注輪盤

開局前設定，結束時輸家轉輪盤。預設選項：

- 餵對方吃一口
- 幫對方買飲料
- 按摩 5 分鐘
- 幫對方拍 10 張美照
- 今天洗碗
- 說三個對方的優點
- ✏️ 自訂

### 戰績紀錄（存在手機本機，不用帳號）

- 歷史勝負場數
- 最常用的魚 / 漁夫
- 稱號：「最會假咬的人」、「提竿之神」、「斷線王」、「餌料殺手」

### 吃飯友善

- 一隻手就能玩
- 一局很短，可以隨時暫停（上菜了！）
- 不用聲音也能玩，靠震動和畫面提示

## 7. 技術方向（之後開發參考）

| 項目 | 方案 |
|---|---|
| 前端 | 純網頁：HTML + Canvas + JavaScript，可愛卡通 + Emoji 畫風 |
| 連線 | PeerJS（WebRTC P2P），用 4 位數房號 / QR code 配對 |
| 部署 | GitHub Pages（免費、不用伺服器） |
| 判定 | 開房間的手機當「主機」，負責所有判定，另一支只送操作 → 兩邊結果一定一致 |
| 存檔 | localStorage（戰績、自訂懲罰） |

**已知風險**

- 部分行動網路的 NAT 可能讓 P2P 連不上 → 提示「兩人連同一個 Wi-Fi」，之後可加 TURN 伺服器
- iOS Safari 不支援網頁震動 → iPhone 改用畫面閃爍 + 音效

### MVP 範圍建議

**第一版**

- 4 魚（鯉魚、鯊魚、河豚、章魚）+ 4 漁夫（老漁夫、海盜、科學家、阿嬤）
- 階段一 + 階段二 + 結算
- 房號連線、賭注輪盤

**第二版**

- 其餘角色（電鰻、小丑魚、網紅、小屁孩）
- 隨機事件、對方視角重播、快速嗆聲
- 戰績與稱號
